# qa-agent-kit

Agent skills for test design, test-quality review, and QA effort estimation.

This is a companion package, not part of [Dev Doc Harness](https://github.com). It does not depend on that harness. Install it into a product repository the same way you would install a Cursor skill package.

## What it is for

- Design tests for new behavior using standard test-design techniques
- Review PRs against unit / integration / e2e / smoke best practices for UI and API
- Record QA effort when estimating a ticket

## Artifacts

Work for a ticket or change lives under:

```text
docs/qa/<ticket-or-slug>/
  test-cases.md
  test-review.md
  qa-estimate.md
```

## Status
